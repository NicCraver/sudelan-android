# 速删 v0.2 Design

Approved by user 2026-09-07.

## Goals
Enrich beyond single-stream swipe while keeping the frozen gesture base:
- up = next, down = previous, right-throw = soft-delete, axis locking.

## Bottom tabs (Douyin-like)
1. **刷删** — full-screen swipe stream (default)
2. **相册** — multi-image grid; tap jumps into 刷删 at that item; optional multi-select soft-delete
3. **回收站** — soft-deleted items; restore; empty → one system MediaStore batch delete
4. **我的** — today/total soft+permanent stats, approx freed space, 重新浏览 (clear seen), light settings later

## Delete model
- Right-swipe / grid delete → **in-app recycle bin** (hide from album + stream). No MediaStore delete yet.
- Restore from bin → back to album/stream.
- Empty recycle bin → single `createDeleteRequest` / batch system confirm; then remove from bin permanently.
- Pending staging from v0.1 merges into recycle bin semantics.

## Seen photos
Unchanged: persist viewed IDs; filter on load; 重新浏览 clears.

## Packaging
APK asset: `速删-{versionName}-debug.apk` (e.g. `速删-0.2.0-debug.apk`).
Tag: `v0.2.0-debug`.

## Out of scope v0.2
Accounts, paywall, smart dedupe, folders, iCloud/cloud sync UI.
